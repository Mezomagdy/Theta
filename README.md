## About this repository

This repository collects the source code and narration scripts behind the educational videos on [@mezo-magdy](https://www.youtube.com/@mezo-magdy). Each video has its own folder so its code, script, and notes stay together.

## Tools

- [Python](https://www.python.org/)
- [Manim Community Edition](https://www.manim.community/)
- [NumPy](https://numpy.org/)

## Add a new video

Create a numbered folder under videos/, for example videos/002-your-topic/. Put Manim scenes in src/, narration and notes in scripts/, and add a row with the YouTube link and thumbnail to the table above.
